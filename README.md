# Glassmorphism Login Page 🔒

A modern, responsive, and aesthetically pleasing Login Page built using HTML5 and CSS3 featuring a glassmorphism (frosted glass) design effect.

## 🌟 Features

- **Glassmorphism UI**: Uses `backdrop-filter: blur()` and subtle borders for a frosted glass card effect.
- **Custom Form Controls**: Username and Password input fields with integrated [Boxicons](https://boxicons.com/) icons.
- **Interactive Elements**: Checkbox for "Remember me", links for "Forgot password?", and "Register".
- **Responsive Layout**: Centered card design using CSS Flexbox.

---

## 🛠️ Built With

* **HTML5**: Semantic markup for form elements.
* **CSS3**: Custom styling, flexbox centering, frosted glass backdrop filters, and custom input styling.
* **Boxicons**: Vector icons for user and lock fields.

## 🚀 How to Run Locally

### Option 1: Directly in Browser
Double-click `index.html` or open it with your favorite browser (Chrome, Edge, Firefox, etc.).

### Option 2: Using VS Code Live Server
1. Open the project folder in **VS Code**.
2. Right-click `index.html` and select **Open with Live Server**.

### Option 3: Using a Local Server
Run a local Node server using `npx`:
```bash
npx serve .
```
Then visit `http://localhost:3000` in your web browser.
